# AI Support Ticket Triage

An end-to-end Machine Learning project that classifies customer support tickets into categories and urgency levels using classical ML and Transformer models.

## Tech Stack

- Python
- Poetry
- Pandas
- Scikit-learn
- Hugging Face Transformers
- FastAPI
- Docker
